# Security reports

Do not post vulnerabilities, credentials, private driver code, or sensitive
device captures in public issues or pull requests.

If GitHub's **Security > Report a vulnerability** option is available, use it
to submit a private report. Otherwise, contact your Ambiq support representative
to arrange a private reporting channel before sending sensitive details.

Include the affected release or commit, board, transport, reproduction steps,
and expected impact. Remove credentials and personal data from attachments.

This is demonstration firmware, not a medical device or a production security
reference. A fix or support timeline is not guaranteed for every release.
